I'm a **B.Tech Biotechnology student at NIT Durgapur (2027)** and a **BS Data Science and Applications student at IIT Madras**. I work across the data lifecycle: collecting and cleaning data, validating information, designing relational databases, automating workflows, and communicating findings.
